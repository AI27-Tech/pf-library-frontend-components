# PF Frontend Component Library

A reusable React.js component library for the AI 27 team's frontend projects.

## Tech Stack

- React.js
- TypeScript

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Project Structure

```
src/
  components/    # Reusable UI components
  styles/        # Shared styles and tokens
```
